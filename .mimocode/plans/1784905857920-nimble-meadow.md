# Plan: Batch profile scan — MCP + CLI

## Contexto

El usuario quiere poder escanear rangos de IDs para descubrir docentes de su facultad. Actualmente tanto el MCP (`dutic_get_person_profile`) como el CLI (`dutic profile`) solo aceptan un userId específico. La SKILL.md ya fue actualizada previamente (la prohibición de scraping masivo fue eliminada).

**Objetivo:** Añadir soporte para resolver múltiples perfiles en lote, tanto en el MCP como en el CLI, con concurrencia limitada y caché individual.

## Cambio 1: Dominio — `getBatchPersonProfiles` en people.ts

**Archivo:** `src/domain/people.ts`

Añadir una función `getBatchPersonProfiles` que:
- Acepta `userIds: number[]` + `opts: { concurrency?: number, onProgress?: callback }`
- Usa `mapLimit` (ya importado) con concurrencia por defecto 4
- Cada perfil se resuelve individualmente con `getPersonProfile` o `getPersonProfileAuto` (ya cacheado con `withCache`)
- Filtra IDs inválidos (Moodle responde "usuario no válido") — los omite silenciosamente
- Devuelve `PersonProfile[]` con solo los perfiles válidos
- Progreso reportado vía `onProgress` (fase, done, total, label)

**Código aproximado (insertar después de `getPersonProfileAuto`, línea ~325):**

```typescript
export interface BatchProfileOptions {
  concurrency?: number;
  courseId?: number;
  onProgress?: (info: { phase: string; done: number; total: number; label?: string }) => void;
}

export async function getBatchPersonProfiles(
  session: Session,
  userIds: number[],
  opts: BatchProfileOptions = {},
): Promise<PersonProfile[]> {
  const { concurrency = 4, courseId, onProgress } = opts;
  let done = 0;
  return mapLimit(userIds, concurrency, async (id) => {
    try {
      const prof = courseId
        ? await getPersonProfile(session, id, courseId)
        : await getPersonProfileAuto(session, id);
      onProgress?.({ phase: "perfiles", done: ++done, total: userIds.length, label: `${id}` });
      return prof;
    } catch {
      onProgress?.({ phase: "perfiles", done: ++done, total: userIds.length, label: `${id} (omitido)` });
      return null;
    }
  }).then((results) => results.filter((p): p is PersonProfile => p !== null));
}
```
